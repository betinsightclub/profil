# BetInsight Geschäftspräsentation

In diesen Ordner kommt später die freigegebene Geschäftspräsentation als PDF.

Empfohlener Dateiname:

`BetInsight-Geschaeftspraesentation.pdf`

Die Seite `marketing-center/index.html` erkennt PDF-Dateien in diesem Ordner automatisch.
Sobald die PDF hochgeladen ist, werden im Marketing-Center die Schaltflächen
„PDF ansehen“ und „PDF herunterladen“ eingeblendet.

Die Seite muss anschließend nicht erneut geändert werden.
