# TIME CLASH Branding

Approved web branding assets (2026-09-29).

- `time-clash-wordmark-header.png` — 360×117 PNG, transparent and web-optimized; canonical TIME CLASH header/wordmark.
- `time-clash-seal-stamp.png` — 160×157 PNG, transparent and web-optimized; supporting seal/stamp for cards, homepage banners and promotional modules.

Usage rule: TIME CLASH pages use the wordmark in the top header instead of the general BetInsight logo. The seal is supporting key art/stamp, not the permanent navigation header.

The repository intentionally stores lightweight web derivatives so every TIME CLASH page loads quickly.
