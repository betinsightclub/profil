Gebührenübersicht

Plisio-Gebühr Die Plisio-Servicegebühr wird je Währung, Netzwerk, Betrag und Auszahlungsweg aktuell berechnet. Bei Sofortauszahlung trägt sie der Admin. Bei Sammelauszahlung übernimmt BetInsight diese Gebühr. –
Netzwerkgebühr Diese Gebühr entsteht im jeweiligen Blockchain-Netzwerk und kann sich bis zur Auszahlung verändern. Sie wird in beiden Auszahlungsarten vom Admin getragen. –
Wer trägt die Plisio-Gebühr? Admin
Wer trägt die Netzwerkgebühr? Admin
Voraussichtlicher Empfang –
Bei einer Sammelauszahlung ist die heutige Anzeige nur eine Schätzung. Am tatsächlichen Auszahlungstag werden die Gebühren erneut abgefragt.
